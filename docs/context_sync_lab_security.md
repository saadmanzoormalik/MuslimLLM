# Context Sync Lab Security

Every imported item is untrusted reference data. Historical `system`, `developer`, and tool records never enter Muslim LLM's actual instruction hierarchy. During promotion they are converted to wrapped reference messages.

Archive controls block traversal paths, absolute paths, drive paths, symlinks, executables, excessive file counts, excessive decompressed size, and suspicious compression ratios. Script-like and executable-signature files are quarantined as metadata. No imported code is executed.

Text scanning identifies instruction override language, secret/system-prompt requests, local-file exfiltration, safety-disable requests, hidden HTML, data URLs, and long base64-like blocks. Findings remain visible in `openai_import_exceptions` and the validation report.

Local defaults are:

```text
CONTEXT_SYNC_LOCAL_PROCESSING=true
CONTEXT_SYNC_ALLOW_CLOUD_CONTENT_UPLOAD=false
CONTEXT_SYNC_LOCAL_FILES_ONLY=true
```

The cloud authentication broker receives no export content, prompts, project names, files, continuity summaries, or local database rows.
