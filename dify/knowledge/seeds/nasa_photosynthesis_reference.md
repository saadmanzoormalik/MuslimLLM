# Photosynthesis reference

Photosynthesis converts light energy into stored chemical energy. Plants use light, water, and carbon dioxide to produce sugars and release oxygen. This is an original summary of the linked government educational source.

Official source: NASA STEMonstrations: Photosynthesis.
https://www.nasa.gov/stem-content/stemonstrations-photosynthesis/

The source was last updated January 26, 2024. Religious text is not used as empirical evidence for this biological process.
